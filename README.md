# Matt Studio PH - Digital Designer Portfolio

A sleek, modern portfolio website for Matthew Ramirez, showcasing UI/UX Design and Graphic Design work.

## 🎨 Features

- **Parallax Scrolling Effects** - Dynamic visual experience with layered animations
- **Responsive Design** - Fully mobile-optimized with adaptive layouts
- **Modern UI** - Gradient backgrounds, smooth transitions, and interactive elements
- **Dark Theme** - Eye-friendly color scheme with cyan, indigo, and pink accents
- **Fast Performance** - Optimized for speed and smooth 60fps animations
- **GitHub Pages Ready** - Deploy directly to your GitHub Pages site

## 📱 Sections

1. **Hero** - Engaging landing section with call-to-action buttons
2. **About** - Professional bio and background information
3. **Skills** - Organized skill categories (Design, Frontend, Technical, Tools, Other)
4. **Portfolio** - Featured work and projects showcase
5. **Contact** - Contact information, form, and social links

## 🚀 Getting Started

### Prerequisites
- GitHub account
- Git installed locally

### Installation

1. Clone this repository:
```bash
git clone https://github.com/mattstudioph/mattstudioph.github.io.git
cd mattstudioph.github.io
```

2. Open `index.html` in your browser to preview locally

3. Push to GitHub:
```bash
git add .
git commit -m "Initial portfolio commit"
git push origin main
```

4. Your portfolio will be live at: `https://mattstudioph.github.io`

## 🎯 Customization Guide

### Update Personal Information
Edit these sections in `index.html`:
- Hero section with your name and title
- About section bio
- Skills cards and competencies
- Portfolio projects
- Contact information and social links

### Customize Colors
Edit CSS variables in `css/styles.css` (`:root` section):
```css
--primary-color: #00d4ff;      /* Cyan */
--secondary-color: #8b5cf6;    /* Indigo */
--accent-color: #ff006e;       /* Pink */
--dark-bg: #0a0e27;            /* Dark background */
```

### Add Portfolio Projects
Duplicate the portfolio item in the portfolio grid and update:
- Background gradient colors
- Project title and description
- Tags/skills
- Link to project

### Update Social Links
Modify the social links in the contact section:
- GitHub URL
- LinkedIn URL
- Add additional social profiles as needed
